# Quran Mazid Clone

A high-fidelity clone of the [QuranMazid.com](https://quranmazid.com) interface, built with modern web technologies.

## Features
- **Modern UI**: Dark mode by default, matching the original aesthetics exactly.
- **Surah List**: Navigate through all 114 Surahs with translation and transliteration.
- **Ayah View**: Beautifully rendered Arabic text with Saheeh International translation.
- **Settings**: Customizable font sizes for both Arabic and English text.
- **Responsive**: Works on desktop and mobile.

## Tech Stack
- **Framework**: [Next.js](https://nextjs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **API**: Quran.com API v4

## Getting Started

First, install the dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Deployment

This project is ready to be deployed on [Vercel](https://vercel.com).

1. Install Vercel CLI: `npm i -g vercel`
2. Run `vercel login`
3. Run `vercel` in the project root
